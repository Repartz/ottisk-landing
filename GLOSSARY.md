# Глоссарий

## Бренд

- **OTTISK** — название команды (произносится: "От-тиск"). От слова "отпечаток".
- **OTTISK Lab** — Telegram-канал команды (`@ottisk_lab`).

## Дизайн

- **Тёплый антрацит** — базовый цвет фона `#141210`. НЕ чёрный.
- **Золото OTTISK** — primary `#C4A962`. Акцентный цвет CTA, hover-эффектов.
- **Тёплый охристый** — `#D4A574`, для градиентов и glow.
- **Терракота** — accent `#B87333`, дополнительный акцент.
- **Тёплый графит** — `#2A2520`, фон карточек и модалок.
- **Тёплый белый** — text `#F5F0E8`, основной текст.
- **Тёплый серо-бежевый** — text-muted `#9A8B7A` (он же t60).

## Анимации

- **Kinetic Typography** — слова появляются по одному с GSAP. Используется в Hero, About, Testimonials.
- **Stroke draw** — SVG-линии "рисуются" через `stroke-dashoffset` (Preloader, Process timeline).
- **Spring-физика** — `cubic-bezier(0.34, 1.56, 0.64, 1)`, упругое замедление (FAQ, Modal).
- **ScrollTrigger** — GSAP плагин для скролл-анимаций (видео-фон, kinetic, timeline).
- **Hover glow** — золотое свечение через box-shadow (карточки, кнопки).
- **Parallax** — эффект глубины при скролле (Hero: видео + текст с разной скоростью).
- **Grain overlay** — фиксированный шум поверх всего сайта (`opacity: 0.03`, mix-blend: overlay).

## Технические термины

- **App Router** — Next.js 14 маршрутизация через файловую систему `app/`.
- **localePrefix: 'as-needed'** — настройка next-intl: дефолтная локаль (RU) без префикса в URL.
- **prefers-reduced-motion** — медиа-запрос, уважающий настройки пользователя по сокращению анимаций.
- **HTTP-only cookie** — cookie, недоступный из JavaScript (защита от XSS).
- **Lazy-инициализация** — отложенная загрузка (Firebase подключается только если ключи заданы).
- **Smart Header** — шапка, которая прячется при скролле вниз и появляется при скролле вверх.

## SEO

- **Schema.org Organization** — JSON-LD разметка для поисковиков (Google, Yandex).
- **OG-image** — Open Graph image, превью при шаринге в соцсетях (`/og-image.jpg`, 1200×630).
- **hreflang** — атрибут для альтернативных языковых версий (для SEO).
- **canonical URL** — основной URL страницы (предотвращает дубли в индексе).

## Пользовательские термины

- **CTA** — Call-to-Action, главный призыв к действию (у нас — "Написать в Telegram").
- **Brief** — техническое задание + согласование с клиентом.
- **Onboarding** — первый этап сотрудничества, формализация требований.
- **Spec table** — таблица спецификаций услуг (ORYZO-стиль).
